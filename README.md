# Инструмент визуализации графа зависимостей пакетов (Вариант №4)

## 1. Общее описание

CLI-приложение на языке Python для анализа и визуализации графа зависимостей пакетов экосистемы **Rust (Cargo)**. Программа самостоятельно извлекает метаданные о зависимостях без использования штатных менеджеров пакетов или сторонних библиотек разрешения зависимостей, строит транзитивный граф методом поиска в ширину (BFS с рекурсией), поддерживает поиск обратных зависимостей и формирует графическое представление на языке диаграмм **D2**, а также в виде **ASCII-дерева**.

---

## 2. Описание функций и настроек

### Конфигурационный файл (`config.csv`)

Настройки приложения задаются в файле формата **CSV** (разделитель — запятая `,`).

| Параметр | Тип / Значения | Описание |
| :--- | :--- | :--- |
| `package_name` | Строка (например, `serde`) | Имя анализируемого пакета (или условного узла `A`, `B`, `C` в режиме тестирования). |
| `repository_url` | URL или путь к файлу | Адрес репозитория пакетов (`crates.io` / `Cargo.toml`) или путь к локальному файлу графа. |
| `test_mode` | `true` / `false` | Включение режима работы с локальным тестовым файлом графа. |
| `ascii_tree` | `true` / `false` | Включение вывода дерева зависимостей в консоль в формате ASCII-дерева. |
| `reverse_deps` | `true` / `false` | Режим поиска обратных зависимостей (пакетов, зависящих от целевого пакета). |

### Основные модули и функции (`src/`)

* `load_config(config_path)` — чтение параметров из CSV-файла и валидация значений (проверка существования файла, корректности URL/пути и булевых флагов).
* `fetch_direct_dependencies(package_name, repo_url)` — выполнение HTTP-запроса к репозиторию пакетов Cargo и парсинг списка прямых зависимостей без сторонних утилит.
* `load_test_graph(file_path)` — загрузка графа из локального текстового файла для отладки на тестовых примерах.
* `build_dependency_graph_bfs(start_package, repo_source)` — рекурсивный обход в ширину (BFS) для построения полного графа транзитивных зависимостей с защитой от бесконечных циклов.
* `find_reverse_dependencies(target_package, graph)` — поиск всех пакетов, которые прямо или транзитивно зависят от заданного пакета, на базе алгоритма обхода BFS.
* `generate_d2_diagram(graph)` — формирование текстового описания графа зависимостей на языке диаграмм **D2**.
* `render_ascii_tree(graph, root_package)` — форматирование и вывод иерархии зависимостей в виде псевдографического ASCII-дерева.

## 3. Сборка проекта и запуск тестов

Проект реализован на стандартной библиотеке Python 3 (внешние зависимости для анализа не требуются).

### Запуск приложения

Запуск через скрипт для Windows:
```powershell
run.bat
```
Или напрямую из терминала с передачей пути к конфигурационному файлу:
```powershell
python -m src.main --config config.csv
```
### Запуск модульных тестов

Для проверки парсинга конфигурации, обработки ошибок, обхода графа и обработки циклических зависимостей используется модуль unittest:
```powershell
python -m unittest discover -s tests -v
```

## 4. Примеры использования

### Пример 1. Конфигурационный файл (config.csv) для реального пакета

```csv
package_name,repository_url,test_mode,ascii_tree,reverse_deps
serde,https://crates.io/api/v1/crates,false,true,false
```

Результат вывода ASCII-дерева в консоль:
```text
serde
├── serde_derive
│   ├── proc-macro2
│   │   └── unicode-ident
│   ├── quote
│   │   └── proc-macro2 (cycle/visited)
│   └── syn
└── serde_core
```

### Пример 2. Режим тестирования на локальном графе

Файл тестового репозитория (tests/test_graph.txt):
```text
A: B, C
B: D
C: D, E
D: A
E:
```

Конфигурация (config_test.csv):
```csv
package_name,repository_url,test_mode,ascii_tree,reverse_deps
A,tests/test_graph.txt,true,true,false
```

### Пример 3. Сгенерированное описание графа на языке D2

```d2
direction: down

A -> B
A -> C
B -> D
C -> D
C -> E
D -> A
```
